# Review notes (personal branch)

Personal working notes for PALE contributions. This is an orphan branch: it shares no history with `main` and is **not meant for a pull request**.

| Path | Content |
| :--- | :--- |
| `memory.md` | Standing rules and the current state of every PR. Read this first when resuming. |
| `history.md` | Decision log: what was decided, when and why. |
| `tasks/tax-packet/notes.md` | #102 implementation notes: story line, code structure, grader, discussions, draft comment, to-do |
| `tasks/task-env-map.mmd` | Mermaid map of tasks and the environments they depend on |
| `environments/counterline/` | #219 ADR and design review |
| `environments/casefold/` | #222 architecture review |
| `drafts/pr-descriptions/` | PR description drafts, one per PR |
| `drafts/replies/` | Review replies, posted or pending |

Not included on purpose: raw conversation transcripts, personal contact details, and implementation code. Implementation lives on its own `task/*` and `env/*` branches.
