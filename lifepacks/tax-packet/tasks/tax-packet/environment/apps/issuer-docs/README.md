# Issuer document page for Task #102 (task-owned, v0.1.0)

A read-only document page of a fictional bank, Bayview Bank, owned by Task #102 (`tax-packet`). Rowan's savings account there closed on 2025-08-29; its 2025 Form 1099-INT becomes available on 2026-03-10, so the agent has to fetch it itself.

- `accounts.list`, `documents.list` (per account, optional kind and tax year, newest first) and `documents.download` (bytes and SHA-256).
- A document appears when the virtual clock reaches its `available_from` time. Before then it is neither listed nor downloadable, and a download reads exactly like an unknown document.
- No writes and no incoming events. Bytes are part of the seed and are validated against their size and SHA-256.

The seed is generated by `environment/build/make_issuer_seed.py` from the task's synthetic documents.

```sh
npm test
npm run example
npm run contracts:check
```

From the repository root:

```sh
npm run app:verify -- --app lifepacks/tax-packet/tasks/tax-packet/environment/apps/issuer-docs
```
